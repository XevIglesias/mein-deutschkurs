# Mein Deutschkurs

Mi curso de alemán, de A0 al **ÖSD Zertifikat B2**. Una sola página, sin cuentas
y sin servidor: se abre y funciona.

**→ https://xeviglesias.github.io/mein-deutschkurs/**

Cuatro pestañas: **Libro** (las lecciones y la chuleta de gramática), **Vocab**,
**Práctica** (ejercicios, tarjetas con repetición espaciada, test y drills de
errores) y **Plan**.

11 Lektionen · clases C001–C020 · 432 palabras.

El progreso se guarda en el navegador del propio móvil (`localStorage`). Si
borras los datos del navegador, se pierde.
